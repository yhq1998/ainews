# AI 动态

一个单文件的 AI 资讯看板：打开网页即可看到最新的 AI 行业动态，页面会定时自动刷新，并像新闻播报一样循环滚动。

## 功能

- **定时刷新**：默认每 5 分钟拉取一次最新内容，可选 1 / 5 / 15 / 30 分钟或关闭；支持手动刷新（快捷键 `R`）
- **滚动播报**：资讯卡片匀速向上循环滚动，可调速度（慢 / 中 / 快 / 关）；鼠标悬停自动暂停
- **新动态提醒**：新条目带 `NEW` 标记并高亮，浏览器标签页标题显示未读数量
- **筛选与搜索**：精选 / 全部、24 小时 / 7 天、按分类（模型、产品、行业、论文、技巧）、关键词搜索
- **热点榜**：侧栏实时显示当前热点 Top 10
- **深浅色主题**：跟随系统，也可手动切换
- 筛选条件、刷新间隔、滚动速度等设置保存在浏览器本地

## 使用

整个项目只有一个 `index.html`，没有构建步骤，也没有任何依赖。

- **本地使用**：直接用浏览器打开 `index.html`
- **部署**：把 `index.html` 放到任意静态文件服务器（Caddy、Nginx、对象存储等）即可

## 说明

- 数据通过浏览器直接请求公开的只读资讯接口获取，无需 API Key，也不需要后端
- 接口请求带条件缓存（`ETag` / `If-None-Match`），内容未变化时几乎不消耗流量；遇到限流会自动按 `Retry-After` 退避
- 摘要与翻译由 AI 生成，引用数字、政策或原话前请回原文核对
